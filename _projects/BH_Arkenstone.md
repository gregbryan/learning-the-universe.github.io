This project is exploring the use of the Arkenstone-hot framework {% cite ArkenstoneI %} to model the high-specific energy outflows in BH-generated jets. The BH jet implementation is described in {% cite 2026arXiv260503154S %}, building on cosmological results from the stellar wind model {% cite 2025MNRAS.543.1456B %}.
